# Changelog

## [1.0.1] - 2026-04-06

### Fixed
- Added missing `com.apple.security.files.bookmarks.app-scope` entitlement required for security-scoped bookmark persistence in sandboxed builds

## [1.0.0] - 2026-04-06

### Added
- Per-display video wallpaper selection via menu bar
- Looping video playback using AVQueuePlayer
- Security-scoped bookmark persistence across launches
- Global play/pause controls
- Launch at login via ServiceManagement
- Support for MP4, MOV, QuickTime, and WebM formats
